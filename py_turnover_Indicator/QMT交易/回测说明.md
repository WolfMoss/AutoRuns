# 小市值策略回测使用说明

## 环境配置问题解决

### 问题1：xtquant模块导入错误
```
ModuleNotFoundError: No module named 'xtquant.IPythonApiClient'
```

### 解决方案：

#### 方案1：正确安装xtquant（推荐）
1. **找到QMT安装目录**
   - 通常在：`E:\迅投极速策略交易系统交易终端 大同证券QMT实盘\userdata_mini`
   - 或类似路径

2. **复制xtquant文件夹**
   - 在QMT安装目录下找到 `xtquant` 文件夹
   - 完整复制到Python的site-packages目录
   - 例如：`D:\codes\Python\Python312\Lib\site-packages\`

3. **验证安装**
   ```python
   try:
       from xtquant import xtdata
       print("xtquant安装成功")
   except Exception as e:
       print(f"安装失败：{e}")
   ```

#### 方案2：使用独立回测系统（不依赖xtquant）
如果无法正确配置xtquant，可以使用我们提供的独立回测系统。

## 回测文件说明

### 1. 小市值策略回测.py
- **依赖**：需要xtquant正常工作
- **功能**：使用真实历史数据回测
- **适用**：QMT环境配置正确的用户

### 2. 独立回测系统.py（新增）
- **依赖**：仅需pandas, numpy, matplotlib
- **功能**：使用模拟数据演示策略逻辑
- **适用**：无法配置QMT环境的用户

## 使用步骤

### 步骤1：环境准备
```bash
pip install pandas numpy matplotlib
```

### 步骤2：选择回测方式
- 如果QMT配置正常：使用 `小市值策略回测.py`
- 如果QMT配置有问题：使用 `独立回测系统.py`

### 步骤3：运行回测
```bash
python 独立回测系统.py
```

### 步骤4：查看结果
回测完成后会生成：
- 净值曲线图
- 回测数据CSV文件
- 交易记录CSV文件

## 参数调整

可以在代码中调整以下参数：
```python
class SmallCapBacktest:
    def __init__(self):
        self.max_holdings = 10        # 最大持仓数量
        self.max_price = 20.0         # 股价上限
        self.position_ratio = 0.1     # 单股仓位比例
        self.commission_rate = 0.0003 # 手续费率
        self.stamp_tax = 0.001        # 印花税
```

## 注意事项

1. **数据来源**：
   - 真实回测需要QMT提供历史数据
   - 独立回测使用模拟数据，仅供策略逻辑验证

2. **结果解读**：
   - 关注夏普比率和最大回撤
   - 模拟回测结果仅供参考，不代表实际收益

3. **风险提示**：
   - 历史表现不预示未来收益
   - 实盘前请充分测试和验证
