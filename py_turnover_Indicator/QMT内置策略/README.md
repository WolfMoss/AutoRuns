# QMT小市值策略使用说明

## 策略概述

这是一个基于QMT客户端的小市值股票投资策略，旨在通过投资市值较小的股票来获取潜在的超额收益。

## 策略特点

### 1. 执行频率
- **周频交易**：每周一14:00自动执行
- 避开早盘波动，选择下午相对稳定的时间段

### 2. 选股条件
- **股票池**：A股所有股票
- **排除标准**：
  - ST股票（包括*ST、ST等）
  - 科创板股票（688开头）
  - 北交所股票（43、83开头）
  - 新三板等其他板块
- **价格限制**：股价不超过20元
- **选股数量**：市值最小的10只股票

### 3. 交易逻辑
- **持仓检查**：判断当前持仓是否在最新选出的10只股票中
- **卖出规则**：如果持仓股票不在新选股票中，全部卖出
- **买入规则**：如果持仓股票少于10只，买入新选出且未持仓的股票
- **仓位管理**：每只股票买入账户总市值的1/10

### 4. 风险控制
- **分散投资**：最多持有10只股票
- **等权重配置**：每只股票占比相等
- **向下取整**：买入手数向下取整，避免超额投资

## 策略参数

| 参数名称 | 默认值 | 说明 |
|---------|--------|------|
| max_positions | 10 | 最大持仓股票数量 |
| max_price | 20 | 最高股价限制（元） |
| 仓位比例 | 1/10 | 每只股票占账户总市值比例 |

## 关键函数说明

### 1. `select_target_stocks()`
- 功能：选择目标股票
- 流程：获取股票列表 → 过滤条件 → 计算市值 → 排序选取

### 2. `execute_trades()`
- 功能：执行交易决策
- 流程：对比持仓 → 卖出调整 → 买入补充

### 3. `calculate_target_position()`
- 功能：计算目标持仓数量
- 逻辑：账户总市值 ÷ 10 ÷ 股价 = 目标股数（向下取整到手）

## 注意事项

### 1. 数据依赖
- 策略依赖QMT的实时行情数据
- 需要财务数据支持（总股本信息）
- 确保数据接口权限已开通

### 2. 交易限制
- 仅在交易时间内执行
- 需要足够的资金支持买入操作
- 考虑股票停牌等特殊情况

### 3. 风险提示
- **市值偏小风险**：小市值股票波动较大，存在较高风险
- **流动性风险**：部分小市值股票可能存在流动性不足
- **集中度风险**：策略相对集中在小市值股票
- **时间风险**：固定时间执行可能错过最佳交易时机

### 4. 合规要求
- 确保账户有足够权限进行程序化交易
- 遵守相关法规和券商要求
- 建议先进行小资金测试
