# 港股新闻关键字监控系统

## 功能介绍
本系统可以自动监控港股新闻，当发现包含指定关键字的新闻时，会自动发送邮件通知。

## 主要特性
- ✅ 增量更新：只获取新的新闻，避免重复处理
- ✅ 关键字匹配：支持多个关键字监控
- ✅ 邮件通知：匹配到关键字时自动发送邮件
- ✅ 配置文件：支持灵活的配置管理

## 文件说明

### 核心文件
- `main.py` - 主程序文件
- `requirements.txt` - 依赖包列表

### 配置文件
- `search_words.txt` - 搜索关键字配置（必需）
- `emails.txt` - 邮箱地址配置（必需）
- `email_config.py` - 邮件服务器配置（必需）

### 自动生成文件
- `last_news_title.txt` - 保存上次处理的新闻标题（自动生成）

## 配置步骤

### 1. 安装依赖
```bash
D:\codes\Python\Python312\python.exe -m pip install -r requirements.txt
```

### 2. 配置搜索关键字
编辑 `search_words.txt` 文件，添加你要监控的关键字，用英文逗号分隔：
```
加密,稳定币,区块链,数字货币
```

### 3. 配置邮箱地址
编辑 `emails.txt` 文件，添加接收通知的邮箱地址，用英文逗号分隔：
```
139069910@qq.com,huaixieyuan@gmail.com
```

### 4. 配置邮件服务器
编辑 `email_config.py` 文件，配置发送邮件的邮箱信息：

#### QQ邮箱配置示例：
```python
SMTP_SERVER = "smtp.qq.com"
SMTP_PORT = 587
EMAIL_USER = "your_email@qq.com"
EMAIL_PASSWORD = "your_authorization_code"  # QQ邮箱授权码
```

#### 获取QQ邮箱授权码：
1. 登录QQ邮箱网页版
2. 点击"设置" -> "账户"
3. 找到"POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务"
4. 开启"IMAP/SMTP服务"
5. 生成授权码，将授权码填入`EMAIL_PASSWORD`字段

## 定时运行（可选）
可以使用Windows任务计划程序或者其他定时工具，设置程序定时运行，比如每小时运行一次。

## 注意事项
1. 确保网络连接正常
2. 邮箱授权码要正确配置
3. 关键字匹配不区分大小写
4. 程序会自动添加延时，避免请求过于频繁

## 故障排除

### 邮件发送失败
- 检查email_config.py配置是否正确
- 确认邮箱授权码是否有效
- 检查网络连接是否正常

### 找不到新闻内容
- 检查网络连接
- 确认目标网站是否可以正常访问

### 关键字不匹配
- 检查search_words.txt文件编码是否为UTF-8
- 确认关键字拼写是否正确
